## Analysis recipe

1. **Identify cores and extract their spectra**: Cores are closed contours above 3 sigma in continuum maps; spectra are averaged over all pixels in each polygon  
  > "identified a core within continuum emission maps of Sgr B2(M) and N, if at least one closed contour (polygon) above the 3$\sigma$ level" (3 Data analysis); "are obtained by averaging over all pixels contained in a polygon to improve the signal-to-noise and detection of weak lines" (3 Data analysis)
   - software: CASA, STATCONT
   - parameter: Continuum map rms 8 mJy/beam; 3 sigma threshold  
  > "with $\sigma$ the root mean square (rms) noise level of the map: 8 mJy beam$^{-1}$" (3 Data analysis)
   - parameter: Spectral rms per source from iterative sigma clipping (68% of points kept)  
  > "rms noise level was determined using an iterative sigma clipping approach." (Footnote 3)
   - fitting: _not stated_
   - validation: _not stated_
2. **Set up the XCLASS LTE two-layer model**: 1D radiative transfer in LTE with an isothermal source; components with size, Trot, Ntot, line width and velocity offset; core layer (emission) and envelope layer (absorption, beam filling)  
  > "XCLASS allows modeling and fitting of molecular and recombination lines by solving the 1D radiative transfer equation assuming local thermal equilibrium (LTE) conditions and an isothermal source." (3 Data analysis); "For all cores in Sgr B2(M) and N, we assume a two-layer model, where all components belonging to a layer have the same distance to the observer." (3 Data analysis)
   - software: XCLASS, MAGIX
   - parameter: Core source size = diameter of a circle with the same area as the polygon  
  > "is given by the diameter of a circle that has the same area" (3 Data analysis)
   - parameter: Envelope-layer components assumed to fill the beam  
  > "we assume beam filling for all components located in the envelope layer" (3 Data analysis)
   - parameter: Isotopologs fitted with the main species using fixed ratios (12C/13C=20, 16O/18O=250, 32S/34S=13, 16O/17O=800, 32S/33S=75, 14N/15N=182, 35Cl/37Cl=3); deuterated ratio free  
  > "the $^{16}$O/$^{18}$O to be 250 and $^{32}$S/$^{34}$S to be 13" (3 Data analysis); "If deuterated isotopologs are identified, we leave the ratio as an additional fit parameter." (3 Data analysis)
   - parameter: Line overlap handled with an average source function per frequency and distance  
  > "XCLASS takes the local line overlap into account, by computing an average source function $S_l (\nu)$ for each frequency $\nu$ and distance $l$." (3 Data analysis)
   - assumption: LTE valid because of high H2 column densities; Trot approx Tkin  
  > "LTE is a valid approximation and the kinetic temperature of the gas can be estimated from the rotation temperature" (3 Data analysis)
   - assumption: Isothermal source  
  > "assuming local thermal equilibrium (LTE) conditions and an isothermal source" (3 Data analysis)
   - fitting: _not stated_
   - validation: _not stated_
3. **Fit all molecules and RRLs to each core spectrum**: Initial parameters from earlier surveys, adjusted by eye, then Levenberg-Marquardt via MAGIX; CO and HCN modelled phenomenologically; final simultaneous fit of all molecules and RRLs including continuum parameters  
  > "Subsequent to adjusting of the parameters by eye, we made use of the Levenberg-Marquardt algorithm to further improve the description." (3 Data analysis); "Finally, we fit again all parameters describing the contributions of all identified molecules and RRLs simultaneously" (3 Data analysis)
   - software: XCLASS, MAGIX
   - parameter: Molecule identified if enough unblended lines exceed 5 sigma and the model predicts no strong undetected line  
  > "A molecule is claimed as identified if a sufficient number of lines are stronger than the 5$\sigma$ level of the random noise, are not blended, and if the model does not predict a strong line that is not detected." (3 Data analysis)
   - parameter: CO and HCN: Trot fixed to 200 K for emission and 2.7 K for absorption components  
  > "we have fixed the excitation temperatures for components describing emission features of these species to a value of 200 K." (3 Data analysis); "For components describing absorption features, we assume a temperature of 2.7 K." (3 Data analysis)
   - parameter: A line is unidentified if the model describes less than 20% of its height  
  > "we declare a line as unidentified if the model describes less than 20 % of the height of the line." (Footnote 5)
   - assumption: Gaussian profiles for molecules, Voigt profiles for radio recombination lines  
  > "using Voigt line profiles instead of Gaussian line profiles" (3 Data analysis)
   - fitting: MAGIX with Levenberg-Marquardt optimisation; fits repeated with all species simultaneously  
  > "XCLASS includes the MAGIX optimization package, which is used to fit these model parameters to observational data." (3 Data analysis)
   - validation: Unidentified-line fraction per source (7-31% in M, 14-37% in N for the main cores)  
  > "the proportion of unidentified lines ranges from 14 % (A06) and 37 % (A03)" (3 Data analysis)
4. **Estimate parameter errors by MCMC for a proxy case**: emcee affine-invariant ensemble sampler on OCS and CH3CN of core A03 in Sgr B2(M), starting at the best-fit LTE model  
  > "to perform a Markov chain Monte Carlo (MCMC) algorithm that approximates the posterior distribution of model parameters by random sampling in a probabilistic space" (3 Data analysis)
   - software: emcee, XCLASS
   - parameter: 40 walkers  
  > "draws 40 samples (walkers) of model parameters from the likelihood function in a ball around this position." (3 Data analysis)
   - parameter: 1500 steps per parameter  
  > "For each parameter we used 1500 steps to sample the posterior." (3 Data analysis)
   - parameter: Column densities sampled in log10  
  > "the errors for the column densities were calculated on a log scale" (3 Data analysis)
   - assumption: OCS and CH3CN of A03 serve as proxy for the reliability of all other parameters  
  > "We have therefore determined the errors of the model parameters for OCS and CH$_3$CN of core A03 in Sgr B2(M) as a proxy for the other parameters" (3 Data analysis)
   - fitting: emcee ensemble MCMC; likelihood-based, priors not stated; HPD intervals reported  
  > "The probability distribution and the corresponding highest posterior density (HPD) interval of each model parameter are calculated afterward." (3 Data analysis)
   - validation: Posterior distributions are unimodal for all parameters  
  > "For all parameters we find a unimodal distribution, which means that there is no other fit within the given parameter ranges that describes the data so well." (3 Data analysis)
5. **Derive abundances and mean temperatures per source**: Abundances relative to H2 using per-source hydrogen column densities from Paper VII; for multi-component molecules, column-density weighted mean temperature and summed abundances  
  > "We calculated the abundances relative to H$_2$ using the hydrogen column densities derived in our first paper for each source." (4 Results); "we give the column density weighted mean temperature and the summed abundances" (4 Results)
   - software: XCLASS
   - fitting: _not stated_
   - validation: Compared with literature temperature and abundance ranges (tables in the paper)  
  > "A comparison between the obtained temperature and abundance ranges for each source in Sgr B2(M) and N and literature values are given in Table" (4 Results)
6. **Kernel density estimates of Trot, line width and velocity offset**: Gaussian-kernel KDE per source, layer and molecular family for components of Sgr B2 only (v > 22 km/s) and molecules with more than one transition  
  > "Here, we consider only those components that clearly belong to Sgr B2; that is, whose source velocity is greater than $22$ km s$^{-1}$" (5.1 Physical parameters); "In addition, we take only those molecules into account, which show more than one transition within the frequency ranges covered by our observations." (5.1 Physical parameters)
   - software: scipy
   - parameter: Gaussian kernel, Silverman's rule bandwidth (scipy), each KDE normalised to a maximum of one  
  > "Silverman’s rule as scipy implementation is used to compute the bandwidth of each KDE." (5.1 Physical parameters); "For a better visibility, we have normalized the maximum of each KDE to one." (5.1 Physical parameters)
   - assumption: Thermal line widths (0.1-0.6 km/s) are small, so line widths mainly trace turbulence  
  > "Therefore, the distribution of line widths mainly shows the turbulent contribution." (5.1 Physical parameters)
   - fitting: _not stated_
   - validation: _not stated_
7. **PCA and k-means clustering of source abundances**: PCA on core-component abundances relative to H2 (sources with v > 22 km/s), then k-means in PC space with the elbow method to choose the number of clusters  
  > "but use the calculated abundances relative to the hydrogen column densities derived in our first paper for each source of the core components" (5.2 Correlations between sources); "the k-means function from the scikit-learn package is used to categorize the cores into a predefined number of distinct, non-overlapping clusters" (5.2 Correlations between sources)
   - software: scikit-learn, yellowbrick
   - parameter: Elbow at six clusters for M and seven for N  
  > "For sources in Sgr B2(M), the elbow is at six and for N at seven clusters." (5.2 Correlations between sources)
   - assumption: Sources of the same age have similar abundance sequences  
  > "Here, we assume that two sources of the same age also have great similarities in the sequence of their abundances." (5.2 Correlations between sources)
   - fitting: _not stated_
   - validation: Clusters checked against cluster mean temperatures/abundances; authors note filaments and low S/N can distort clusters  
  > "In addition to the level of evolution of the source, other contributions such as filaments can also play a role in the classification of the sources into the various clusters." (5.2 Correlations between sources)
8. **Kendall rank correlation between sources**: Kendall tau between abundance sets of each pair of sources, threshold |tau| >= 0.9 for good correlation  
  > "The coefficient is calculated for each pair of sources" (5.2 Correlations between sources); "Setting an (arbitrary) threshold at $\ge|0.9|$ to indicate a good correlation" (5.2 Correlations between sources)
   - fitting: _not stated_
   - validation: _not stated_
9. **Classify evolutionary phase from masers, outflows and H II regions**: Phase from presence of class II CH3OH, H2O, NH3, H2CO, OH masers, H II regions and outflow line wings (SO, OCS); all non-Gaussian line wings taken as outflows  
  > "Following and , we used the distributions of masers, outflows and H ii regions to determine the evolutionary sequence and age" (5.3 Evolutionary sequence); "Here, we assume that all non-Gaussian line-wings indicate outflows." (5.3 Outflows)
   - assumption: Averaged polygon spectra may contain several protostars  
  > "This means that the averaged spectra may contain contributions from different protostars." (5.3 Evolutionary sequence)
   - fitting: _not stated_
   - validation: Compared with earlier classification of N1-N4 in Sgr B2(N)  
  > "We have identified the same evolutionary stages for sources A08 (associated with N3) and A13 (associated with N4) in Sgr B2(N) as are reported by ." (5.3 Classification)
10. **Order sources by chemical clocks**: Rank sources from young to old by abundance ratios SO2/SO, SO2/OCS, vibrationally excited analogues, CH3CN/CH3OH and cyanide ratios  
  > "Since H$_2$S has no transition in the frequency ranges covered by our observations, we only use the ratios of SO$_2$/OCS and SO$_2$/SO to estimate the age." (5.4 Chemical clocks); "The sources in each row are ordered from young to old (evolved), whereby the absolute age is different for each row." (Table notes (chemical clocks))
   - assumption: H2S remains the primary sulfur reservoir on dust mantles  
  > "However, for the purposes of the further analysis, we shall maintain the assumption that H$_2$S remains the primary reservoir for sulfur on dust mantles." (5.4 Chemical clocks)
   - fitting: _not stated_
   - validation: Orders from vibrationally excited ratios broadly consistent with those from ground-state ratios; no uniform order across ratios  
  > "In general, we do not obtain a uniform order of the various sources in Sgr B2(M) and N." (5.4 Chemical clocks)

## Qualitative findings

- Sgr B2(N) hot cores show more complex molecules (CH3OH, CH3OCHO, CH3OCH3) while M cores contain lighter molecules (SO2, SO, NO)  
  > "Sgr B2(N) hot cores show more complex molecules such as CH$_3$OH, CH$_3$OCHO, and CH$_3$OCH$_3$, while M cores contain lighter molecules such as SO$_2$, SO, and NO." (abstract)
- Some sulfur-bearing molecules are more abundant in N than in M  
  > "Some sulfur-bearing molecules are more abundant in N than in M." (abstract)
- Inner sources are generally more evolved than outer sources, with exceptions  
  > "Inner sources in both regions were generally more developed than outer sources, with some exceptions." (abstract)
- Filaments appear to be embedded with some Sgr B2(N) sources and may distort chemical clocks, PCA and Kendall results  
  > "Furthermore, some sources in Sgr B2(N) seem to be embedded in filaments connecting different sources." (6 Conclusions); "the contribution of filaments distorts this correlation and the results of the chemical clock, PCA and Kendall coefficient analysis may give incorrect results" (6 Conclusions)

## Reasoning

- Why this data: ALMA's high sensitivity used to characterise the hot core population  
  > "Using ALMA’s high sensitivity, we aim to characterize the hot core population in Sgr B2(M) and N" (abstract)
- Why this method: LTE modelling justified by high H2 densities; PCA applied to abundances instead of spectra to avoid line-overlap and absorption distortion  
  > "LTE is a valid approximation and the kinetic temperature of the gas can be estimated from the rotation temperature" (3 Data analysis); "By using abundances, the results of the PCA are not distorted by line overlap or absorption features." (5.2 Correlations between sources)
- Alternative: Kendall tau chosen over Pearson or Spearman correlation  
  > "Here, we use the Kendall instead of the Pearson or Spearman correlation coefficient, because the Kendall correlation is more robust and efficient" (Footnote 10)
- Alternative: PCA not applied directly to observed spectra, unlike other PCA analyses  
  > "we do not apply PCA directly to the observed spectra" (5.2 Correlations between sources)
- Alternative: SiO excluded from outflow analysis because of self-absorbed profiles  
  > "Due to its large optical depth, SiO shows self-absorbing line profiles, which is why we do not consider it further in the analysis." (5.3 Outflows)
- How they decided it was enough: Number of k-means clusters chosen at the elbow of the within-cluster sum of squares curve  
  > "The point of maximum curvature in the plot called elbow or knee represents the point where the WCSS starts to decrease at a slower rate." (5.2 Correlations between sources)
- Limitation (authors): Reliable error estimation for all model parameters not feasible; errors derived only for OCS and CH3CN of A03 in M  
  > "Due to the large number of model parameters, a reliable estimation of the errors is not feasible within an acceptable time." (3 Data analysis)
- Limitation (authors): Many unidentified features in weaker cores are imaging artifacts that can also distort real lines  
  > "Many of the unidentified spectral features toward the weaker cores are actually due to imaging artifacts in this high dynamic range cube." (3 Data analysis)
- Limitation (authors): Noise level may be dominated by weak lines rather than thermal noise  
  > "we cannot exclude the possibility that the determined noise level is still dominated by weak lines instead of thermal noise." (Footnote 3)
- Limitation (authors): Averaged polygon spectra can include several protostars, and non-Gaussian line shapes may be infall rather than outflow  
  > "Furthermore, the emission spectra of each source were averaged over several pixels, so that not every source is caused by a single protostar." (6 Conclusions); "non-Gaussian line shapes can be caused not only by outflows but also by infall motions" (6 Conclusions)
- Limitation (authors): Envelope excitation temperatures underestimated in this analysis relative to Paper VII  
  > "Therefore, we underestimate in this analysis the real excitation temperatures in the envelopes around each source." (5.1 Physical parameters)
- Caveat (inferred, ours): LTE and isothermal single-layer assumptions per component are not tested against non-LTE or radiative-transfer models.
- Caveat (inferred, ours): Errors only for two molecules in one core, so quoted abundance differences between sources have no uncertainty.
- Caveat (inferred, ours): Evolutionary phase assignment depends on maser and H II catalogues not documented here and on unresolved multiple protostars per polygon.
- Caveat (inferred, ours): PCA and k-means on abundances with many missing molecules per source may reflect detection limits and S/N rather than evolution.
- Caveat (inferred, ours): Possible beam-size dependence: all images smoothed to 0.4 arcsec but source sizes come from polygons.
