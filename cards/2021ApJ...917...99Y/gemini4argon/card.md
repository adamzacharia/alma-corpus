- Question: What are the sub-kpc spatial structure, lensing configuration, physical properties, and gas kinematics of the host galaxy of the z=6.51 gravitationally lensed quasar J0439+1634?

## Analysis recipe

1. **Calibrate visibilities, subtract continuum, and image continuum and [C II] line**: Fit linear continuum to line-free channels with UVCONTSUB, perform phase self-calibration on continuum and apply to line visibilities, and clean both using TCLEAN with Briggs weighting.  
  > "We use the task UVCONTSUB [^1] to fit a linear function to the line-free channels, which models the continuum, and subtract the continuum model to obtain the line-only visibility." (Data); "We then use the continuum data to perform phase self-calibration and apply the self-calibration model to the line-only data." (Data); "We clean the continuum and line data with the CASA task TCLEAN using Briggs weighting, setting robust $=0.5$." (Data)
   - software: CASA, UVCONTSUB, TCLEAN
   - parameter: robust = 0.5  
  > "We clean the continuum and line data with the CASA task TCLEAN using Briggs weighting, setting robust $=0.5$." (Data)
   - parameter: linear function for UVCONTSUB  
  > "We use the task UVCONTSUB [^1] to fit a linear function to the line-free channels, which models the continuum, and subtract the continuum model to obtain the line-only visibility." (Data)
   - fitting: Linear fit in UVCONTSUB  
  > "We use the task UVCONTSUB [^1] to fit a linear function to the line-free channels, which models the continuum, and subtract the continuum model to obtain the line-only visibility." (Data)
   - validation: _not stated_
2. **Extract lensed continuum and [C II] fluxes and fit 1D [C II] line profile**: Extract continuum and [C II] fluxes using a 2.0'' diameter aperture and fit a 1D Gaussian profile to the [C II] spectrum using SPECFIT.  
  > "We extract the continuum and [C ii] fluxes of J0439+1634 with a $2.0\ensuremath{''}$ diameter aperture, which gives $S_\text{245 GHz}=16.0\pm0.1 \text{ mJy}$ for the continuum and $F_\text{[C\,{\sc ii}]}=14.5\pm0.2\text{ Jy km s}^{-1}$ for the integrated [C ii] flux." (Data); "We also fit a Gaussian profile to the [C ii] line using the CASA task SPECFIT." (Data)
   - software: CASA, SPECFIT
   - parameter: aperture diameter = 2.0''  
  > "We extract the continuum and [C ii] fluxes of J0439+1634 with a $2.0\ensuremath{''}$ diameter aperture, which gives $S_\text{245 GHz}=16.0\pm0.1 \text{ mJy}$ for the continuum and $F_\text{[C\,{\sc ii}]}=14.5\pm0.2\text{ Jy km s}^{-1}$ for the integrated [C ii] flux." (Data)
   - fitting: 1D Gaussian profile fit  
  > "We also fit a Gaussian profile to the [C ii] line using the CASA task SPECFIT." (Data)
   - validation: Comparison with NOEMA measurements from (cite: yang19)  
  > "are consistent with those in (cite: yang19)." (Physical Properties of J0439+1634, Dust Continuum and [C ii] Emission)
3. **Model gravitational lensing and source surface brightness in the uv-plane**: Use VISILENS to fit an SIE lens + Sérsic source model directly to the continuum and [C II] visibilities using MCMC. In the default model, fix lens mass, ellipticity, and PA to the HST fiducial model, fit lens position on continuum, and fix lens position for [C II].  
  > "In short, VISILENS models the $uv-$plane response of a lens system and obtains the posterior distributions of model parameters using Markov Chain Monte Carlo (MCMC)." (Lensing Model); "Because the continuum has a higher signal-to-noise ratio (SNR), we first fit the continuum to obtain the best-fit lens position, then apply the lens position when fitting the [C ii] emission." (3.1 Building the Lensing Model); "We use a Sérsic profile to describe the source, both for the continuum and the [C ii] line emission." (3.1 Building the Lensing Model)
   - software: VISILENS
   - parameter: Lens redshift = [0.67], Source redshift = [6.5187], Lens Mass = [2.06x10^10 M_sun], Lens e = [0.65], Lens PA = [94.58 deg] (in default model)  
  > "$^{1}$ In the default model, the parameters of the lens galaxy, except its position, are fixed to the fiducial model in (cite: fan19)." (Table 1)
   - assumption: Singular isothermal ellipsoid (SIE) lens mass distribution and single Sérsic source profile  
  > "Specifically, we use an SIE to describe the lens galaxy." (3.1 Building the Lensing Model); "We use a Sérsic profile to describe the source, both for the continuum and the [C ii] line emission." (3.1 Building the Lensing Model)
   - fitting: MCMC in uv-plane via VISILENS; reduced chi^2 = 1.035 (continuum) and 1.014 ([C II])  
  > "In short, VISILENS models the $uv-$plane response of a lens system and obtains the posterior distributions of model parameters using Markov Chain Monte Carlo (MCMC)." (Lensing Model); "The dust continuum of J0439+1634 can be well-fitted by a single Sérsic profile, with a reduced $\chi^2=1.035$." (3.2 Dust Continuum); "The reduced $\chi^2$ of the best-fit model is $1.014$." (3.3 Integrated [C ii] Flux)
   - validation: Tested an 'ALMA-only' model with all lens parameters free, tested alternative HST double/quad lens configurations, and tested adding a second Gaussian component to the source model.  
  > "For comparison, we also build an alternative model, hereafter referred as the “ALMA-only" model, in which we leave all parameters free when fitting the ALMA data and do not use any information from the *HST* observations." (3.1 Building the Lensing Model); "When we add a Gaussian profile to the source model, where we allow the Gaussian profile to have negative flux, the flux of the Gaussian profile converges to zero within the error." (3.2 Dust Continuum)
4. **Reconstruct source-plane [C II] data cube, moment maps, and kinematics**: Attempt uv-plane axisymmetric thin rotating disk fit with VISILENS (rejected due to poor fit). Reconstruct source-plane data cube via inverse ray-tracing of the cleaned image cube onto a 0.04'' grid using the default lens model, compute moment maps for pixels with SNR > 10, and extract PV diagram.  
  > "We thus fit the [C ii] emission using an axisymmetric rotating thin disk, following the method described in (cite: neeleman19)." (3.4 [C ii] Kinematics); "Specifically, we reconstruct the source (i.e., un-lensed) data cube on a grid with a pixel size of $0.04\ensuremath{''}$." (3.4 [C ii] Kinematics); "When calculating the first and the second moments, we only include pixels that have integrated flux SNR larger than $10$." (3.4 [C ii] Kinematics)
   - software: VISILENS
   - parameter: source-plane pixel size = 0.04''  
  > "Specifically, we reconstruct the source (i.e., un-lensed) data cube on a grid with a pixel size of $0.04\ensuremath{''}$." (3.4 [C ii] Kinematics)
   - parameter: integrated flux SNR > 10 threshold for moment 1 and 2  
  > "When calculating the first and the second moments, we only include pixels that have integrated flux SNR larger than $10$." (3.4 [C ii] Kinematics)
   - assumption: Default lensing model mapping from image plane to source plane  
  > "We then trace all the pixels in the image-plane data cube (i.e., the clean image) to the source plane according to the default lensing model." (3.4 [C ii] Kinematics)
   - fitting: Direct extraction of maximum velocity from PV line connecting maximum and minimum moment 1 pixels  
  > "We extract the velocities along the black line, which connects the pixels with the maximum and minimum moment 1 value (i.e., the red and blue peaks)." (3.4 [C ii] Kinematics)
   - validation: Ray-traced the image-plane synthesized beam at the flux peak to verify source-plane resolution (0.26'' x 0.09'') and checked caustic positions for multiply-imaged regions.  
  > "The lower-right corner of the reconstructed moment 0 map illustrates the output when we perform the inverse ray-tracing analysis to an image-plane beam located at the image-plane flux peak." (3.4 [C ii] Kinematics); "The source-plane beam has a size of $0.26\ensuremath{''}\times0.09\ensuremath{''}$, which further illustrates that a source-plane pixel size of $0.04\ensuremath{''}$ is appropriate." (3.4 [C ii] Kinematics)
5. **Derive de-lensed physical properties, spatially resolved [C II] deficit, and dynamical mass**: Correct apparent luminosities, SFR, dust mass, and gas mass from (cite: yang19) using derived continuum and [C II] magnifications. Measure [C II]/FIR vs Sigma_FIR in 4 concentric elliptical rings of width R_eff. Compute dynamical mass from v_max sin(i) and r_max, and evaluate SMBH sphere of influence.  
  > "For [C ii]-based quantities, we apply the magnification of [C ii] emission, $\mu_\text{[C\,{\sc ii}]}=3.44$; for FIR-based quantities, we apply the continuum magnification, $\mu_\text{cont}=4.53$." (4.1 Dust Continuum and [C ii] Emission); "All regions have the same center, ellipticity, and position angle as the continuum emission." (Physical Properties of J0439+1634, Dust Continuum and [C ii] Emission); "Using the maximum line-of-sight velocity $v_\text{max}\sin(i) = 130 \text{ km s}^{-1}$ and the corresponding radius $r_\text{max}=2\text{ kpc}$, we estimate the dynamical mass within $r_\text{max}$ for J0439+1634, $M_\text{dyn}\sin^2(i)=7.9\times10^{9}M_\odot$." (4.2 Host Galaxy Dynamics)
   - parameter: mu_[C II] = 3.44, mu_cont = 4.53  
  > "For [C ii]-based quantities, we apply the magnification of [C ii] emission, $\mu_\text{[C\,{\sc ii}]}=3.44$; for FIR-based quantities, we apply the continuum magnification, $\mu_\text{cont}=4.53$." (4.1 Dust Continuum and [C ii] Emission)
   - parameter: 4 elliptical annuli with width R_eff = 0.136''  
  > "The $n^\text{th}$ region is defined as $n\times R_\text{eff}<R<(n+1)\times R_\text{eff}$, where $n=0,1,2,3$, and $R_\text{eff}=0.136\ensuremath{''}$ is the half-light radius of the continuum emission." (4.1 Dust Continuum and [C ii] Emission)
   - assumption: LambdaCDM cosmology with H0 = 70 km s^-1 Mpc^-1, Omega_M = 0.3, Omega_Lambda = 0.7  
  > "Throughout this paper, we use a $\Lambda$CDM universe with $H_0=70 \text{ km s}^{-1}\text{Mpc}^{-1}$, $\Omega_\text{M}=0.3$, and $\Omega_\Lambda=0.7$." (Introduction)
   - assumption: Dust continuum traces molecular gas (for CO magnification) and SFR surface density  
  > "In addition, we apply the continuum magnification to the CO-based molecular gas mass, assuming that the dust continuum traces the molecular gas." (4.1 Dust Continuum and [C ii] Emission); "Assuming that the dust continuum traces the SFR surface density (SFRD), we estimate the SFRD within the continuum half-light radius" (5.1 A Maximum Star Forming Rotating System)
   - fitting: _not stated_
   - validation: Evaluated effect of turbulent pressure gradient in a thick-disk model on v_c and M_dyn  
  > "Following the discussion in (cite: fsw20), we estimate the circular velocity of the host galaxy, $v_c$:" (4.2 Host Galaxy Dynamics)

## Qualitative findings

- The ALMA lensing model confirms the three-image naked-cusp fiducial HST lens model from (cite: fan19) and rules out the alternative double and quadruple image models.  
  > "The alternative models do not provide suitable fits to the ALMA data. We conclude that the fiducial *HST* model has the correct lensing configuration." (3.1 Building the Lensing Model)
- The [C II] emission is more spatially extended and diffuse than the dust continuum, resulting in a lower magnification factor for [C II] than for the continuum.  
  > "The overall magnification of the [C ii] emission is $3.44\pm0.05$, which is smaller than that of the dust continuum, mainly because the [C ii] profile is more diffused." (3.3 Integrated [C ii] Flux)
- J0439+1634 exhibits a rotation-like velocity field, but its flux major axis (east-west) is misaligned with the velocity gradient (north-south), ruling out an axisymmetric rotating thin disk.  
  > "In contrast, the major axis of the flux distribution of J0439+1634 is roughly aligned east-to-west (Figure 3, right panel), while the velocity gradient is roughly north-to-south (Figure 1)." (3.4 [C ii] Kinematics)
- The smooth morphology, single-peaked Gaussian [C II] line profile, and lack of companion sources within the ~12'' ALMA field of view disfavor an ongoing close major merger or strong [C II] outflow.  
  > "These results suggest that J0439+1634 is not an on-going major merger and does not exhibit significant outflow features in the [C ii] velocity field." (4.1 Dust Continuum and [C ii] Emission)

## Reasoning

- Why this data: J0439+1634 is the only known gravitationally lensed quasar at z > 5, allowing ALMA at ~0.3'' resolution to probe sub-kpc (~0.8 kpc) scales in the host galaxy's dust continuum and [C II] emission.  
  > "J0439+1634 is the only known lensed quasar at $z>5$ to date and provides an excellent chance to study a high-redshift quasar in enhanced spatial resolution due to its large lensing magnification." (Introduction); "Here we report the sub-mm continuum and [C ii] $158~\mu\text{m}$ emission line of J0439+1634 observed by ALMA at a resolution of $\sim 0.3\ensuremath{''}$. With the help of lensing, we reach a physical resolution of $\sim0.8 \text{ kpc}$." (Introduction)
- Why this method: Used VISILENS to model lensing directly in the uv-plane, fixed lens mass parameters to the HST model because HST has ~4x higher spatial resolution (~0.075''), and used simple inverse ray-tracing for the cube to avoid expensive pixelized lens reconstruction.  
  > "The *HST* images have spatial resolution of $\sim 0.075\ensuremath{''}$, which is several times better than the current ALMA data. We thus adopt the lens mass distribution from the fiducial model in (cite: fan19)." (3.1 Building the Lensing Model); "This simple method captures the main features of the quasar host galaxy without expensive pixelized lensing reconstruction." (3.4 [C ii] Kinematics)
- Alternative: ALMA-only lens model (leaving all SIE lens parameters free): gave consistent overall lensing structure, but the HST-fixed default model was preferred for physical properties due to HST's superior resolution.  
  > "Despite tiny differences in details, the two models give the same overall lensing structure." (3.1 Building the Lensing Model); "Because the *HST* images have better resolution, we use the default model to derive the properties of J0439+1634 from this point on." (3.1 Building the Lensing Model)
- Alternative: Alternative double-image and quadruple-image HST lens models from (cite: fan19): rejected because they do not provide suitable fits to the ALMA data.  
  > "The alternative models do not provide suitable fits to the ALMA data. We conclude that the fiducial *HST* model has the correct lensing configuration." (3.1 Building the Lensing Model)
- Alternative: Adding a second Gaussian component (allowing negative flux) to the Sérsic source model to explain continuum residuals: rejected because the Gaussian flux converged to zero within error.  
  > "When we add a Gaussian profile to the source model, where we allow the Gaussian profile to have negative flux, the flux of the Gaussian profile converges to zero within the error." (3.2 Dust Continuum)
- Alternative: Axisymmetric rotating thin disk model in VISILENS: rejected due to large residuals and unphysical best-fit parameters caused by the misalignment between the flux major axis and velocity gradient.  
  > "However, all of these models return large residuals and unphysical best-fit parameters. We thus conclude that J0439+1634 cannot be described by an axisymmetric rotating thin disk." (3.4 [C ii] Kinematics)
- How they decided it was enough: _not stated_
- Limitation (authors): The high-resolution C43-8 ALMA configuration observations from Program 2018.1.00566.S were not yet completed.  
  > "The high-resolution observation with configuration C43-8 is not completed at the time of this paper’s writing." (Data)
- Limitation (authors): The inclination angle i of the host galaxy rotation axis remains unconstrained, leaving sin(i) dependencies in the dynamical mass, gas fraction, and SMBH-to-host mass ratio.  
  > "However, our data cannot be fit by an axisymmetric thin rotating disk, and the inclination of the rotation axis, $i$, remains unconstrained." (Abstract)
- Limitation (authors): The SIE + Sérsic lensing model is an over-simplification that leaves statistically significant residual clumps (4.9% of continuum peak, 8.1% of [C II] peak), and Table 1 uncertainties only include statistical errors.  
  > "Besides, note that the uncertainties only include statistical errors, and do not take into account the systematic errors introduced by the model choice (see Section 3.5 for more discussion)." (Table 1); "The main source of systematic errors is that the SIE + Sérsic lensing model is over-simplified." (3.5 Systematic Uncertainties)
- Limitation (authors): Simple image-plane inverse ray-tracing fails for multiply-imaged pixels inside the caustics, producing a likely artificial low-velocity component in the PV diagram, and suffers from beam smearing.  
  > "The simple inverse ray-tracing method will fail for these areas, and this component is likely an artifact." (3.4 [C ii] Kinematics); "It is hard to correct the beam smearing effect under the current resolution; as such, we still use $M_\text{dyn}\sin^2(i)=7.9\times10^{9}M_\odot$ in the rest of this paper." (4.2 Host Galaxy Dynamics)
- Caveat (inferred, ours): Applying a single spatially averaged continuum magnification (mu=4.53) to the CO molecular gas mass assumes CO and dust have identical spatial distributions; differential magnification could bias M_H2 if CO is more extended like [C II].
- Caveat (inferred, ours): The spatially resolved [C II] deficit analysis uses the smooth parametric Sérsic models evaluated in 4 concentric rings rather than independent de-lensed measurements in each annulus, so the radial trend is largely predetermined by the different Sérsic indices and effective radii of the two fits.
- Caveat (inferred, ours): Inverse ray-tracing of a cleaned image cube averages multiply-imaged pixels with different local magnifications andPSFs, which distorts the source-plane noise properties and beam shape.
