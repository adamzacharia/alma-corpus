## Analysis recipe

1. **identify 3 GHz counterparts**: By-eye 3 GHz source catalogue cross-matched with ALMA >=5 sigma catalogue  
  > "our ALMA $\geq5\sigma$ source catalogue was cross-matched with the aforementioned 3 GHz source catalogue using a $1\ensuremath{''}$ matching radius" (3.1)
   - parameter: 1'' matching radius  
  > "using a $1\ensuremath{''}$ matching radius" (3.1)
   - fitting: _not stated_
   - validation: 106 of 115 matched to VLA-COSMOS 3 GHz catalogue  
  > "We note that 106 out of our 115 radio sources are common with the VLA-COSMOS 3 GHz Large Project catalogue" (3.1)
2. **measure deconvolved radio sizes**: 2D elliptical Gaussian fits in image plane  
  > "we performed two-dimensional elliptical Gaussian fits to the image plane data using the AIPS task `JMFIT`" (3.3)
   - software: AIPS JMFIT
   - parameter: fit restricted to pixels >=2.5 sigma; resolved if FWHM > half the beam; upper limit <0.38''  
  > "the fit was restricted to the pixel values of $\geq2.5\sigma$" (3.3)
   - fitting: _not stated_
   - validation: M15 mock-source simulations  
  > "they were found to be consistent with the input sizes of the mock sources within the uncertainties assigned by the fitting task" (3.3)
3. **size statistics with censoring**: Kaplan-Meier survival analysis for upper limits; log-normal fit; K-S tests  
  > "we applied a similar K-M survival analysis as in Sect. 3.2 to take the upper size limits (left-censored data) into account" (3.3)
   - software: NADA for R
   - fitting: _not stated_
   - validation: _not stated_
4. **spectral index and brightness temperature**: Two-point 1.4-3 GHz indices; Rayleigh-Jeans T_B from 3 GHz flux and deconvolved major axis  
  > "The observed 3 GHz flux densities were converted into a brightness temperature defined via the Rayleigh-Jeans approximation" (3.4)
   - software: BLOBCAT
   - fitting: _not stated_
   - validation: Matched-resolution check on 38 sources gave mean ratio 1.03  
  > "the mean (median) ratio between the spectral indices derived from different resolution data and those based on the matched-resolution data was found to be 1.03 (0.91)" (3.4)

## Qualitative findings

- Radio sizes show no evolution with redshift or morphology; radio size ~1.5-3x larger than dust sizes but similar to mid-J CO sizes.  
  > "The radio sizes are roughly log-normally distributed, and they show no evolutionary trend with redshift, or difference between different galaxy morphologies." (abstract)
