## Software

- **SMURF / dimm** : Dynamical Iterative Map-Maker tool used to reduce the S2LXS SCUBA-2 bolometer time-series data  
  > "We reduce the S2LXS time-series data using the Dynamical Iterative Map-Maker (dimm) tool, part of the Submillimetre Common User Reduction Facility software package (cite: Chapin2013)." (Data reduction)
- **PICARD** : Mosaicking individual PONG scans (mosaic_jcmt_images) and applying a matched filter (scuba2_matched_filter)  
  > "We combine all scans for each PONG region using the picard package within smurf and the recipe mosaic_jcmt_images." (Data reduction); "To optimize the detection of point sources we apply a matched filter to the final mosaic using the picard recipe scuba2_matched_filter." (Data reduction)
- **SWarp** : Resampling PONG tiles to match the astrometric projection and pixel grid of the final science map  
  > "We use the software package SWarp (cite: Betrin2002) to individually resample the PONG tiles (using nearest neighbour interpolation) to match the astrometric projection and pixel grid of the final science map." (Data reduction)
- **Astropy** 4.2.1: Python package used with Photutils for source detection and peak finding  
  > "In this work we use astropy version $4$.$2$.$1$ and photutils version $1$.$0$.$1$" (Simulated SCUBA-2 maps)
- **Photutils** 1.0.1: Detecting sources in the signal-to-noise ratio matched-filtered map using the find_peaks function  
  > "We use Photutils, an astropy affiliated python package to detect sources in the S2LXS XMM-LSS signal-to-noise ratio matched-filtered map." (Source extraction); "In this work we use astropy version $4$.$2$.$1$ and photutils version $1$.$0$.$1$" (Simulated SCUBA-2 maps)

## Qualitative findings

- The S2LXS XMM-LSS 850 um number counts show a characteristic upturn at bright flux densities (>15 mJy) above a Schechter function fit.  
  > "The S2LXS XMM-LSS observed number counts show the characteristic upturn at bright fluxes, expected to be motivated by local sources of submillimetre emission and high-redshift strongly lensed galaxies." (Abstract)
- There are no Galactic objects in the S2LXS XMM-LSS >5sigma catalogue, and 16 (40 per cent) of the sources have a bright, massive foreground galaxy within the SCUBA-2 beam indicative of strong lensing.  
  > "query the NASA/IPAC Extragalactic Database (NED) for nearby $z<0.1$ sources, allowing us to confirm that there are no Galactic objects in the S2LXS XMM-LSS catalogue." (Bright-end number counts of the $\mathbf{ 850}\,\mu\rm{\mathbf m}$ population); "We find that for $16$ ($40$ per cent) sources in the S2LXS XMM-LSS catalogue there is a bright, massive foreground galaxy within the SCUBA-2 beam." (Bright-end number counts of the $\mathbf{ 850}\,\mu\rm{\mathbf m}$ population)

## Reasoning

- Why this data: XMM-LSS and E-COSMOS were selected for their wealth of legacy multi-wavelength data and accessibility to submillimetre/millimetre interferometers; wide area (>10 deg^2) at moderate depth is needed to probe rare ultra-bright (>15-20 mJy) SMGs.  
  > "and so a moderate depth survey at $850\,\mu{\rm m}$ with an area ${>10}\,{\rm deg}^2$ is needed to properly probe this far-infrared luminous, and potentially high redshift population of galaxies." (Introduction); "These fields were selected to take advantage of the wealth of legacy multi-wavelength data available (this data is essential for identifying SMG counterparts) and for the accessibility to key submillimetre/millimetre interferometers for follow-up observations." (The SCUBA-2 Large eXtragalactic Survey)
- Why this method: Blind source extraction is used instead of a prior-based approach because about 20 per cent of 850 um SMGs are undetected in sensitive near-infrared imaging.  
  > "However, about $20$ per cent of SMGs that are detected at $850\,\mu{\rm m}$ are undetected in sensitive near-infrared imaging at $K\gtrsim25.7\,{\rm mag_{\rm AB}}$ (cite: Dudzevi19). To avoid overlooking this otherwise obscure minority of the SMG population we opt for a blind source extraction approach" (Source extraction)
- Alternative: Processing the simultaneous 450 um SCUBA-2 data was rejected because the estimated sensitivity (1sigma ~ 50 mJy beam^-1) is insufficient to reliably detect sources.  
  > "Although SCUBA-2 simultaneously collects data at both 850$\,\mu{\rm m}$ and 450$\,\mu{\rm m}$ we do not process the complementary 450$\,\mu{\rm m}$ data. At 450$\,\mu{\rm m}$ the estimated sensitivity is $1\sigma\simeq 50\,{\rm mJy\,beam}^{-1}$" (The SCUBA-2 Large eXtragalactic Survey)
- Alternative: Astrometric refinement by stacking on HSC-Wide y-band data or per individual PONG scan was rejected due to inadequate signal-to-noise in the optical stack and insufficient HerMES sources per single PONG tile.  
  > "In our tests (using the stacking method detailed below) with the HSC-Wide *y*-band data ($\lambda_{\rm eff} = 0.9762\,\mu{\rm m}$) we do not get an adequate signal-to-noise in the final stack for a robust measurement of the offset in $\alpha$ and $\delta$." (Astrometric refinement and registration); "However, there are not a sufficient number of HerMES sources within the footprint of each PONG tile to robustly measure the astrometry offset for each observation" (Astrometric refinement and registration)
- Alternative: Estimating the false detection rate using the inverse of the science map (with negative bowling masked) was tested as a check and gave comparable results to the adopted jackknife approach.  
  > "As a check we repeat our analysis but instead of using the jackknife map to estimate the number of spurious detections, we use the inverse of the S2LXS XMM-LSS match-filtered signal-to-noise map." (False detection rate)
- How they decided it was enough: The survey was scaled back from 1sigma ~ 2 mJy beam^-1 to 1sigma ~ 4 mJy beam^-1 due to bad weather on Mauna Kea, which still achieves the primary goal of uncovering the bright end; the 5sigma detection threshold was chosen to give a 90 per cent purity rate.  
  > "Progress of the survey was slow due to ongoing bad weather conditions on Mauna Kea and S2LXS XMM-LSS was consequently scaled back with the revised aim to map the S2LXS XMM-LSS field to a target sensitivity of $1\sigma\simeq4\,{\rm mJy\,beam}^{-1}$." (Observations); "The S2LXS XMM-LSS survey formal detection threshold of $>5\sigma$ is chosen to give a $90$ per cent purity rate." (False detection rate)
- Limitation (authors): Blind source extraction cannot separate multiple discrete sources blended within the coarse 15 arcsec resolution of the SCUBA-2 beam, and imposing a 15 arcsec separation limit may exclude clustered or merging sources.  
  > "We caveat that a limitation of using a blind source extraction approach is that we will not separate out multiple discrete sources blended in the coarse $15$ arcsec resolution of the SCUBA-2 beam (cite: Simpson2015; Stach2018)." (Source extraction); "However, we note that if bright sources are clustered (cite: Cairns2022; Greenslade2020) or are part of merging systems, imposing this separation limit may potentially exclude some sources." (Source extraction)
- Limitation (authors): Number counts above 30 mJy suffer from low number statistics (only one source with observed flux >30 mJy) and large Poisson uncertainties.  
  > "The S2LXS XMM-LSS catalogue only includes one source with an observed flux density $S_{\rm 850\mu m}>30\,{\rm mJy}$, and so our survey is hampered by low number statistics in this flux regime." (Bright-end number counts of the $\mathbf{ 850}\,\mu\rm{\mathbf m}$ population)
- Caveat (inferred, ours): No ALMA data are reduced or analysed in this paper; ALMA project 2022.1.01030.S is only cited as future follow-up work.
