## Analysis recipe

1. **Remove secondary companion HD 34700B from visibility table**: Create a CLEAN model of HD 34700B within an elliptic mask and subtract model visibilities using CASA uvsub()  
  > "To do so, we create a CLEAN model of HD 34700 B CLEANing down to $5\mu\rm{Jy/beam}\,(\approx 1\sigma)$ within an elliptic CLEAN mask of $R=0.625\ensuremath{''}$ ($i=41.5$) centred around B." (Data); "We then remove the `tclean` model visibility from the data set using the `uvsub()` task of CASA (cite: CASA_2022) to obtain the final measurement set used in this work." (Data)
   - software: CASA, tclean, uvsub
   - parameter: CLEAN threshold = 5 uJy/beam (~1 sigma), elliptic mask R = 0.625'', i = 41.5  
  > "To do so, we create a CLEAN model of HD 34700 B CLEANing down to $5\mu\rm{Jy/beam}\,(\approx 1\sigma)$ within an elliptic CLEAN mask of $R=0.625\ensuremath{''}$ ($i=41.5$) centred around B." (Data)
   - fitting: _not stated_
   - validation: _not stated_
2. **Image continuum emission and measure RMS noise, peak intensity, and azimuthal contrast**: CLEAN continuum visibilities with CASA tclean, compute RMS in outer annulus and deproject to polar coordinates with gofish, and compute azimuthal contrast  
  > "We image the continuum data using the `tclean()` task of the CASA software (cite: CASA_2022), version 6.6.5-31." (Imaging); "We use the `gofish` package (cite: GoFish) to compute the Root Mean Square (RMS) noise in annulus between $2.5\ensuremath{''}-4\ensuremath{''}$ for HD 34700 A and IRS 48, and between $3\ensuremath{''}-4\ensuremath{''}$ for HD 142527." (Imaging); "We define the contrast as the ratio between the peak intensity and the azimuthal average of the ring emission, masking the asymmetry contribution when it becomes higher than $16\sigma$" (Continuum images)
   - software: CASA, tclean, gofish
   - parameter: CLEAN threshold = 3 sigma, robust = 0.0 (or 0.5 for IRS 48 in Table 1), pixel sizes 0.015'', 0.009'', 0.025''  
  > "CLEAN the images down to $3\sigma$ using a robust parameter of $0.0$, chosen to provide the best balance between resolution and sensitivity." (Imaging); "We produce a $2000\times2000$ pixels image with pixel size of $0.015\ensuremath{''}$ for HD 34700 A, a $1024\times1024$ pixels image with pixel size of $0.009\ensuremath{''}$ for IRS 48, and a $1024\times1024$ pixels image with pixel size of $0.025\ensuremath{''}$ for HD 142527." (Imaging)
   - parameter: Polar interpolation grid: 501 x 2001 (R, theta) with R in [0, 4]'' and theta in [-180, 180] deg  
  > "and then interpolate the resulting image on a $501\times2001$ ($R, \theta$) grid, with $R\in[0, 4]\ensuremath{''}$ and $\theta\in[-180,180]\degree$." (Section 4.1 Continuum images)
   - assumption: 10% ALMA flux calibration uncertainty for Band 6 and 7  
  > "We measure the peak intensity for all the images, estimating its uncertainty as the $10\%$ ALMA flux calibration error for band 6 and 7." (Continuum images)
   - fitting: _not stated_
   - validation: Compare contrast defined via azimuthal average with contrast defined relative to emission shifted by 180 deg  
  > "For reference, we also report a contrast of $45$, $365$ and $33$ if defined as the ratio between the peak intensity and the emission at the opposite side of the disc (i.e., same radius and PA shifted by $180\degree$)." (Continuum images)
3. **Parametric visibility modelling of circular and eccentric disc morphologies**: Fit 2D parametric brightness models (central/offset Gaussian + Gaussian ring + 1 or 2 asymmetric Gaussian arcs) to visibilities using galario and emcee  
  > "We use the code `galario` (cite: Tazzari_2018) to fit the visibility data and characterize the morphological structure of the continuum emission." (Methods); "We assume a 2D parametric intensity model and follow a Markov Chain Monte Carlo (MCMC) approach implemented with the package `emcee` (cite: Foreman-Mackey_2013)." (Methods); "We use the Gaussian to describe the emission originating inside the cavity, the Gaussian ring, and the Gaussian arcs to model the asymmetric ring" (Section 3 Methods)
   - software: galario, emcee, CASA, tclean
   - parameter: 15 parameters for HD 34700A, 13 for IRS 48, 23 for HD 142527 (plus eccentricity e and argument of periastron omega for eccentric models)  
  > "The models for HD 34700 A, IRS 48 and HD 142527 have a total of $15$, $13$ and $23$ parameters, respectively." (Methods)
   - parameter: Preliminary run: 100 walkers, ~10^3 steps; Fiducial run: 120 walkers, 2x10^4 steps, 25% burn-in  
  > "As initial step we use 100 walkers over $\sim10^3$ steps." (Methods); "For each dataset we set up 120 walkers and $2\times10^4$ steps, and discard the first $25\%$ steps as burn-in." (Methods)
   - assumption: Inner Gaussian fixed to image centre for HD 34700A; no inner Gaussian for IRS 48; same eccentricity for all ring and arc components in eccentric fits  
  > "We choose to fix the inner Gaussian to the image centre for the HD 34700 A model due to its proximity to the ring asymmetry, as the inner Gaussian would merge with the ring otherwise." (Methods); "As a result, we choose not to use a Gaussian component in the model of IRS 48." (Methods); "We fix the eccentricity to be the same for all the ring and arc components in each disc model, and start the fitting procedure using these new parameters." (Disc eccentricity)
   - fitting: MCMC with emcee using uniform priors (log-uniform for fluxes, linear for others); narrow priors on i and PA for HD 34700A and IRS 48  
  > "We perform a preliminary exploration of the parameter space with `emcee` using uniform priors, sampling $f_0$, $f_1$, $f_1^a$ and $f_2^a$ logarithmically and the remaining parameters linearly." (Methods)
   - validation: Checked that unfixing central Gaussian in HD 34700A or allowing wider priors on i and PA keeps parameters within 1 sigma; imaged synthetic model and residual visibilities with tclean  
  > "We check that fixing the Gaussian in the centre does not affect the remaining parameters of the model, as they remain within $1\sigma$ error bars when the Gaussian is not fixed in the centre." (Methods); "We then image the best fit `galario` model and the residuals using the same procedure explained in Sec. 2.3." (Methods); "At a later stage, we check that allowing for wider priors does not significantly change the geometrical parameters." (Visibility Modelling)

## Qualitative findings

- HD 34700A exhibits a 0.46'' (161 au) dust cavity, unresolved inner disc emission, and an asymmetric ring at 0.53'' (186 au) with a trailing tail and contrast of 62, the second highest contrast detected with ALMA in a protoplanetary disc.  
  > "We detect a $0.46\ensuremath{''}$ ($161~\rm au$) large cavity and resolve a ring with an asymmetric crescent and an extended tail at $0.53\ensuremath{''}$ ($186~\rm au$) with peak intensity of $1.9~\rm mJy beam^{-1}$, corresponding to the second highest contrast ($\sim$62) ever detected with ALMA in a protoplanetary disc." (abstract); "We also detect unresolved emission inside the cavity, that we attribute to an inner disc." (abstract)
- The high azimuthal contrast of the asymmetries in HD 34700A, IRS 48, and HD 142527 rules out the orbit clustering of eccentric cavities scenario, while analytical dust trapping and hydrodynamic models support the vortex scenario as plausible.  
  > "The high azimuthal contrast of the asymmetries rules out the orbit clustering of eccentric cavities scenario, while the dust evolution models we consider suggest that the vortex scenario is a plausible option." (abstract)
- Circular and eccentric visibility models of HD 34700A show no substantial difference in residuals, indicating a degeneracy that leaves it unclear whether the ring is circular or eccentric.  
  > "It is interesting to note that the residuals in both the eccentric and circular models do not show any substantial difference." (Disc eccentricity); "This suggests that there is a degeneracy between the circular and eccentric model, and it is currently unclear if the disc around HD 34700 A is circular or eccentric." (Disc eccentricity)

## Reasoning

- Why this data: New high-resolution (0.11'') ALMA Band 6 continuum observations of HD 34700A resolved the ring, cavity, and high-contrast crescent co-located with a tentative kinematic vortex signature, motivating comparison with the two highest-contrast transition discs (IRS 48 and HD 142527).  
  > "In this paper, we present recent ALMA observations of the system HD 34700 AaAb (hereafter HD 34700 A) that resolved a prominent dust asymmetry co-located with a tentative kinematic vortex signature (cite: Stadler_2026)." (Introduction); "We focus on the continuum data of HD 34700 A and perform visibility modelling of the new ALMA Band 6 observations, comparing it with the transition discs with the most prominent asymmetries (with a contrast $\gtrsim30$) from the (cite: vdM2021) sample, namely Oph-IRS 48 (IRS 48 hereafter) and HD 142527." (Introduction)
- Why this method: Visibility modelling with galario and asymmetric Gaussian arcs (plus two arcs for HD 142527) was chosen because previous single-arc models left up to 40% residuals in HD 142527 and did not account for the resolved ring in IRS 48 or the asymmetric trailing tails.  
  > "However, recent observations of IRS 48 also resolve a ring, while a single arc could not fully describe the double peaked emission of HD 142527, as shown by their intensity residuals of up to $40\%$." (Methods); "We use asymmetric arcs with different azimuthal widths on the left ($\sigma_{\theta,\rm l}$) and right ($\sigma_{\theta,\rm r}$) of the peak intensity to better reproduce the tail observed in the continuum images." (Methods)
- Alternative: Orbit clustering in an eccentric disc (rejected due to observed azimuthal contrasts >> 5)  
  > "The high azimuthal contrast of the asymmetries rules out the orbit clustering of eccentric cavities scenario (cite: Ataiee2013)." (Conclusions)
- Alternative: Binary-disc interaction alone carving the large cavities in HD 34700A and HD 142527 (rejected because binary separations of 0.69 au and 10.8 au can only carve cavities up to ~6 a_bin)  
  > "However, with a binary separation of $0.69~\rm au$ for HD 34700 A (cite: Sterzik2005) and $10.8~\rm au$ for HD 142527 (cite: Nowak2024), the observed cavity sizes are too large to be explained by binary interaction alone, as shown by the simulations of HD 142527 in (cite: Penzlin2024)." (Origin of the asymmetry)
- Alternative: Unfixed central Gaussian in HD 34700A and inner Gaussian component in IRS 48 visibility models (rejected because the Gaussian merges with the ring in HD 34700A and fails to recover inner disc emission in IRS 48)  
  > "We choose to fix the inner Gaussian to the image centre for the HD 34700 A model due to its proximity to the ring asymmetry, as the inner Gaussian would merge with the ring otherwise." (Methods); "In the case of IRS 48, adding a Gaussian component to the model does not recover the emission from the inner disc." (Methods)
- How they decided it was enough: _not stated_
- Limitation (authors): The 1D analytical dust trapping model has a highly degenerate parameter space and does not reproduce the elongated trailing tail.  
  > "While this set of parameters results in a model matching the observed intensity azimuthal profile on a qualitative level, it should not be taken as a unique solution." (Dust trapping); "Although this model can reproduce qualitatively the observed intensity azimuthal profile of the peak emission for the HD 34700 A system, it does not recover the elongated trailing tail that we see in Fig.1 and 4." (Dust trapping)
- Limitation (authors): The 2D PLUTO hydrodynamic model is a rescalable proof-of-concept with an aspect ratio profile somewhat high for a passively irradiated disc around HD 34700A, so it does not uniquely constrain exact gas or dust properties.  
  > "Our profile for $h$ is quite in line with expectations beyond 100 au for typical disc parameters, even if possibly rather unrealistic for a passively irradiated disc with the particular stellar parameters for HD 34700 A." (Dust distribution around a massive vortex); "As a result, this model does not necessarily constrain the exact gas or dust properties around HD 34700 A beyond highlighting the requirement for large grains trapped in the vortex, which was already inferred in Sect. 5.1." (Dust distribution around a massive vortex)
- Limitation (authors): Eccentric galario visibility models fail to converge for IRS 48 and HD 142527 and are degenerate with the circular model for HD 34700A.  
  > "In the cases of IRS 48 and HD 142527, the eccentric `galario` models do not reach convergence." (Conclusions)
